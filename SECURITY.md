# Security policy

Do not open a public GitHub issue for a possible security vulnerability, leaked credential, or private-vault exposure. Contact the maintainers privately using the security advisory channel configured on the public repository once it is published.

Until that channel exists, do not submit sensitive details. Open a minimal public issue only asking for a private contact route, or wait for the repository security contact to be published.

`gitu` is experimental and is not a secrets manager. Treat any vault content as ordinary Git content and rotate exposed credentials immediately.
